# Security policy

This repository contains an experimental custom Android kernel. It is a small
community-maintained fork, not a staffed security product or a promise of
security support for a particular ROM or device lifecycle.

## Reporting a vulnerability

Use GitHub's **Private vulnerability reporting** for this repository when it is
available. Include the affected commit or release, impact, reproduction
conditions, and a minimal proof of concept if one can be shared safely.

If private vulnerability reporting is unavailable, contact the maintainer
through a private contact method listed on the maintainer's GitHub profile and
ask for a secure reporting channel before sending sensitive details.

Do not publish live exploit details, signing material, API tokens, private
keys, device identifiers, partition dumps, or personal data in a public issue.
Ordinary non-sensitive compatibility and build bugs should use the issue
forms.

The maintainer will acknowledge reports when possible and coordinate a fix or
responsible disclosure based on severity and available capacity. No fixed
response-time SLA is offered.
